The Great Escape, is a text based python game, where a space marine wakes up in the brig with all his comrades dead. He is then tasked to find a way to escape and avoid being killed by the alien who had infiltrated the ship when he was black out drunk.
The purpose of this project was to practice the use of loops, elif, lists. Dictionaries, and functions.
